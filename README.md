# Car Rental Management System

A C# desktop-based Car Rental Management System developed as an academic project.

## Features

* **Admin:** Manage cars, staff, accountants, and view dashboards, rentals, expenses, and customers.
* **Staff:** Manage customers, rentals, and vehicle maintenance.
* **Accountant:** Manage invoices, payments, and expenses.
* Role-based login and logout.

## Technologies

* C#
* Windows Forms
* SQL Server
* Visual Studio 2022
